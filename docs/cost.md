# 運用コストの目安

> **結論：月額 ¥0 で運用可能** です。Monorize は純粋なブラウザ完結型の
> 静的 SPA であり、サーバ／ストレージ／帯域いずれの追加課金も発生しません。
> ユーザーが既に保有している資源（XServer レンタルサーバ + GitHub 無料
> アカウント）の範囲内で完結します。

本ドキュメントは、Monorize を運用する際に発生し得るコストを整理したものです。
仕様（`../project.md`）とは独立した、運用判断のための参考メモとして扱います。

## 既存資源のみで完結する理由

| 項目 | 必要量 | 既存資源での充足 |
|---|---|---|
| 静的ファイル配信（本番） | HTML / JS / wasm（合計 30〜50 MB 程度） | XServer 既存プラン内で十分（数百 GB のディスク／月転送量に対し微小） |
| 静的ファイル配信（ステージング） | 同上 | GitHub Pages（無料） |
| 計算リソース | 動画変換 = ユーザーのブラウザ／端末で実行 | サーバ側コストはゼロ（ユーザー側 CPU を使う） |
| ストレージ | 動画はサーバに保存しない | 不要 |
| 帯域 | 静的ファイルの初回ダウンロード（≒ 30〜50 MB / ユーザー、以降キャッシュ） | XServer の月転送量に対し微小 |
| TLS 証明書 | あり（HTTPS 必須） | XServer 標準提供（無料）／GitHub Pages 標準提供（無料） |
| ドメイン | 既存ブログのサブパス `/monorize/` で運用 | 既存契約に含まれる |
| コードホスティング | リポジトリ | GitHub 無料アカウントの Private リポジトリ |

## 例外的に発生し得るコスト

通常運用ではゼロですが、以下の選択をする場合は課金が発生します。

- **GitHub Pages を Private リポジトリで使う場合**：GitHub Pro（月 $4 程度）
  へのアップグレードが必要。
  - **回避策**：ステージング用に Public リポジトリを別途作るか、
    ステージングを XServer の別パス（例：`/monorize-staging/`）にする
- **独自ドメインを新規取得する場合**：レジストラ料金（年 $10〜15 程度）。
  既存ドメインのサブパス／サブドメインで済むなら不要
- **10000 件テスト用のサンプル動画を購入・取得する場合**：素材次第。
  本リポジトリ `sample/` にある 6 件を加工・増幅して使うなら不要

## 留意点

- **ユーザー側のブラウザ負荷**：変換処理はユーザー端末の CPU・メモリを
  使うため、ユーザー側のコスト（電力・端末消耗）はゼロではない。ただし
  運営側の課金には影響しない
- **XServer の利用規約**：静的ファイル配信は典型的用途のため通常は問題ない
  が、デプロイ前に
  - サブドメイン／サブパスの追加が許可されていること
  - `.htaccess` の設置が許可されていること（COOP/COEP ヘッダ設定に必須）
  をプランの仕様で確認しておく
- **ffmpeg.wasm のホスト負荷**：wasm 本体は約 25〜30 MB と大きいが、
  HTTP キャッシュが効くため実質的な再ダウンロードは稀。CDN を別途用意
  する必要はない
