使い方

動画を選び、好みのサイズと滑らかさを決め、変換するだけ。すべてあなたのブラウザの中で完結します。

4ステップ

  1. 動画を選ぶ

    ファイルをドラッグ&ドロップするか、「ファイルを選択」ボタンから読み込みます。対応形式は .mp4 / .mov / .avi / .mkv / .webm / .wmv / .flv / .m4v / .ts / .3gp。

  2. パラメータを調整

    横幅・縦幅・フレームレートをスライダーまたは数値入力で指定します。縦横比は元動画にロックされ、片方の値を変えると他方は自動で追従します。

  3. 変換を実行

    「変換を実行」を押すと、ffmpeg.wasm がブラウザ内で動作してモノクロのアニメーション GIF を生成します。動画はネットワーク越しに送信されません。

  4. ダウンロード

    変換が完了したら、そのままダウンロードボタンを押すと GIF が保存されます。タブを閉じるとブラウザ上のデータは消えます。

表示モード

シンプルは最小限のスライダーのみを表示します。詳細では、縦横比ロックの解除、px/% の単位切り替え、縦幅の個別指定ができます。

仕様と制約

項目内容
入力サイズ推奨上限500 MB（超過時に警告ダイアログ。続行可）
出力サイズ警告推定 200 MB 超で警告（推定式 W×H×fps×秒×0.30）
横幅・縦幅下限 32 px、上限は元動画の実サイズ。アップスケール不可
フレームレート1〜30 fps
出力形式モノクロのアニメーション GIF
1 操作あたり1 ファイル（バッチ処理は行いません）

モバイル端末について

!
iPhone / iPad など RAM の少ない端末では、長尺・高解像度の動画でブラウザのメモリ上限を超えると、Safari がタブを強制リロードする場合があります。これは Safari 側の挙動で、本アプリのエラーではありません。

モバイルや旧端末では、まず数十秒程度の短い動画から試すことをおすすめします。PC など RAM に余裕がある環境では 500 MB 程度を目安に扱えます。

変換中・変換後のヒント

変換中はタブを閉じないでください。完了後はブラウザのメモリ上にのみ GIF が保持されるため、ダウンロード前にタブを閉じるとデータは失われます。

出力サイズを抑えたい場合は、横幅を小さくするか、フレームレートを下げてください。同じ尺の動画でも、横幅を半分にするとファイルサイズはおよそ 1/4 になります。
