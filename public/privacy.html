Privacy

動画は、
送信されません。

monorize は純粋な静的 SPA（シングルページアプリ）です。動画の読み込みも変換も、すべてあなたのブラウザの中だけで行われます。

最終更新: 2026年5月15日

動画はサーバへ送られません

ffmpeg.wasm がブラウザ内で動作し、変換に必要な処理はすべてローカルで完結します。元動画も生成された GIF も、私たちのサーバを経由しません。

サーバ側に保存しません

そもそも私たちは動画を保管できる場所を持ちません。タブを閉じる、ページを再読み込みするなどでブラウザのメモリが解放された時点でデータは消滅します。

アカウントもログインも不要

個人を特定する情報の入力は求めません。利用にあたって登録は必要ありません。

取得する情報

monorize は、変換機能の提供にあたって以下の情報を取得・保存しません:

  • 変換した動画の内容
  • 生成された GIF
  • ファイル名・サイズ・解像度などのメタデータ
  • あなたを個人として特定できる情報

配信について

本サイトは GitHub Pages または XServer 上で配信されます。これらの配信元では、一般的な Web サーバの動作として、リクエストログ（接続元 IP アドレス、リクエスト時刻、ユーザーエージェント等）が一定期間記録される場合があります。これは monorize 独自の収集ではなく、配信プラットフォーム側の標準的な挙動です。

monorize 自身は、計測タグ・解析スクリプト・トラッキング Cookie の類を一切埋め込んでいません。

第三者への提供

取得していない情報を提供することはありません。

セキュリティに関する留意点

変換中の動画・GIF は、お使いの端末のブラウザのメモリ上にのみ存在します。共有端末でご利用の場合、変換が終わったらタブを閉じることをおすすめします。

このページの更新

仕様や運用が変わり、本ページの記載と差が生じる場合は内容を更新します。重要な変更がある場合は、更新日とともに変更点を明示します。
